# ربات تلگرام مترجم PDF انگلیسی → فارسی

نسخهٔ سروری پروژهٔ مترجم PDF: کاربر فایل PDF انگلیسی را به ربات می‌دهد و همان فایل را
با حفظ چیدمان (موقعیت/اندازه/بولد/رنگ متن) و چیدمان آینه‌ای راست‌به‌چپ به فارسی تحویل می‌گیرد.

- ربات تلگرام: `@PDFTransla_bot`
- سرویس Render: `https://pdf-translator-bot.onrender.com` (پلن رایگان)
- مخزن: `https://github.com/irbiolop/pdf-translator-bot`

## معماری

| جزء | نقش |
|---|---|
| `bot.py` | پولینگ طولانی تلگرام، صف ترجمه، پنل ادمین، force join، آمار |
| `translator_core.py` | موتور ترجمهٔ PDF با Groq + آینه‌سازی RTL + مقیاس یکنواخت |
| `/health` | وب‌اندپوینت برای keep-alive (GitHub Actions هر ۱۰ دقیقه پینگ می‌زند) |
| `data/state.json` | وضعیت (تنظیمات ادمین + آمار) که به‌صورت خودکار در همین مخزن کامیت می‌شود |

**ذخیرهٔ وضعیت در GitHub:** فایل‌سیستم پلن رایگان Render ماندگار نیست؛ به همین دلیل
تنظیمات ادمین و آمار کاربران هر چند دقیقه در `data/state.json` همین مخزن کامیت می‌شود
و با هر ری‌استارت بازیابی می‌گردد. (این کامیت‌ها redeploy نمی‌کنند چون autoDeploy خاموش است.)

## پنل ادمین (داخل ربات)

به ربات دستور `/admin` بدهید (فقط برای ایدی عددی ادمین):

- 📊 آمار کاربران (کل، فعال ۲۴ ساعت، برترین کاربران)
- 📄 سقف صفحهٔ هر فایل (۱ تا ۵۰۰)
- ⚡ سرعت ترجمه: حداکثر سرعت / متعادل / محتاط (مکث بین درخواست‌های Groq)
- 📢 کانال اجباری: روشن/خاموش + تغییر کانال (`@channel` یا `-100...`)
  - توجه: برای پرسیدن عضویت، ربات باید در آن کانال **ادمین** باشد.
- 💾 ذخیرهٔ دستی وضعیت در GitHub

دستور `/ping` هم اتصال Groq را تست می‌کند.

## متغیرهای محیطی (در Render)

| کلید | توضیح |
|---|---|
| `TELEGRAM_TOKEN` | توکن ربات |
| `GROQ_API_KEY` | کلید Groq |
| `GROQ_MODEL` | پیش‌فرض `openai/gpt-oss-120b` |
| `ADMIN_ID` | ایدی عددی ادمین |
| `GITHUB_TOKEN` | توکن GitHub برای کامیت وضعیت |
| `GITHUB_REPO` | `owner/name` مخزن |
| `PAGE_LIMIT` | سقف پیش‌فرض صفحه |
| `FORCE_JOIN_ENABLED` / `FORCE_JOIN_CHANNEL` | مقادیر اولیهٔ force join |

## نگه‌داشتن سرویس زنده

- `.github/workflows/keepalive-render.yml` — هر ۱۰ دقیقه `/health` را پینگ می‌کند تا سرویس رایگان Render بعد از ۱۵ دقیقه بی‌کاری خواب نرود.
- `.github/workflows/repo-keepalive.yml` — هر ۵ روز یک کامیت خالی می‌زند تا گیت‌هاب طبق سیاست ۶۰ روزه، workflowهای زمان‌بندی‌شده را خاموش نکند.

## به‌روزرسانی کد

autoDeploy خاموش است (کامیت‌های state ربات redeploy راه نیندازد). بعد از پوش کد جدید:

1. داشبورد Render → Manual Deploy، یا
2. API: `POST https://api.render.com/v1/services/{serviceId}/deploys`

## امنیت

- هیچ کلیدی داخل کد نیست؛ همه در متغیرهای محیطی Render هستند.
- توکن‌هایی که در گفتگو برای راه‌اندازی منتقل شدند، پس از راه‌اندازی بهتر است چرخانده شوند (Render → Environment، GitHub → Settings → Developer settings، BotFather → /revoke).
